# java-explore-with-me

pull-request at :

https://github.com/Vitaliy-CatLord/java-explore-with-me/pull/6

Это проект по созданию Ивентов пользователями, заявку на участие в которых могут подать другие пользователи,
\также осуществлена возможность создания комментариев ивентов.

Со стороны в проект входит сервис по подсчету статистики заинтересованности пользователей теми или иными ивентами 

Больше о функциональности основного сервиса можно после запуска контейнера через docker-compose перейдя по ссылке:
http://localhost:8081/ - здесь вы найдете спецификацию Swagger c основными возможностями основного сервиса
